# Universal Design Loop

Operate using evidence-based inspection rather than passive code generation.

## Loop Lifecycle
1. **UNDERSTAND:** Domain facts, user jobs, physical constraints.
2. **INSPECT:** Real application behavior, DOM layout, runtime logs.
3. **BROWSE & CAPTURE:** Real browser inspection across mobile (375px), tablet (768px), and desktop (1280px).
4. **EVALUATE:** Check visual quality, touch target size, contrast, responsive overflows.
5. **PRIORITIZE:** P0 (Critical/Data Integrity), P1 (Major UX/A11y), P2 (Quality), P3 (Refinement).
6. **SPECIFY:** Implementation-ready remediation specification before executing fixes.
